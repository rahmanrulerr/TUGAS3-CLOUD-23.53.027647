Konsep Komputasi Awan

Ringkasan arsitektur, model layanan, serta evaluasi penggunaan teknologi cloud.

Definisi Komputasi Awan (Cloud Computing)

Komputasi awan merupakan metode pengiriman berbagai layanan komputasi—meliputi server, penyimpanan data, basis data, jaringan, hingga perangkat lunak—melalui jaringan internet (cloud). Teknologi ini memungkinkan akses sumber daya secara cepat, fleksibel, dan terukur tanpa perlu membangun pusat data fisik secara mandiri.

SaaS (Software as a Service)

Model layanan di mana aplikasi siap pakai di-hosting oleh penyedia cloud dan diakses langsung oleh pengguna akhir melalui peramban web. Pengguna tidak mengelola infrastruktur maupun kode aplikasi.

Contoh: Google Workspace, Zoom, Dropbox.

PaaS (Platform as a Service)

Menyediakan lingkungan siap pakai bagi pengembang untuk membangun, menguji, dan menyebarkan (deploy) aplikasi tanpa perlu mengatur konfigurasi server atau sistem operasi.

Contoh: GitHub Pages, Vercel, Netlify.

IaaS (Infrastructure as a Service)

Layanan penyediaan infrastruktur komputasi dasar secara virtual (seperti mesin virtual, penyimpanan, dan jaringan) yang memberi kendali penuh atas sistem operasi kepada pengguna.

Contoh: Amazon Web Services (AWS EC2), Google Cloud Compute.

Manfaat & Risiko Layanan Cloud

  • Manfaat: Hemat biaya perangkat keras, akses dari mana saja, kemudahan kolaborasi, dan kapasitas penyimpanan mudah diperbesar.
  • Risiko: Bergantung sepenuhnya pada koneksi internet, risiko kebocoran data jika pengaturan privasi keliru, serta ketergantungan pada vendor penyedia.
